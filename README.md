# Kitchen Safety Monitoring System using Arduino

A basic embedded-system project designed to monitor kitchen environmental conditions using an MQ-2 gas/smoke sensor and a DHT11 temperature and humidity sensor.

## 🔍 Project Overview

This project uses an Arduino UNO to collect readings from an MQ-2 gas/smoke sensor and a DHT11 temperature and humidity sensor.

When the monitored conditions reach the programmed alert threshold, the system provides a warning using an LED and buzzer.

The project was first developed and tested as a circuit simulation and was then implemented using physical hardware and jumper wires.

## ⚙️ Components Used

- Arduino UNO
- MQ-2 Gas/Smoke Sensor
- DHT11 Temperature & Humidity Sensor
- LED
- Buzzer
- Resistor
- Breadboard
- Jumper Wires

## 🔌 Working Principle

1. The MQ-2 sensor monitors gas/smoke levels.
2. The DHT11 measures temperature and humidity.
3. Arduino reads the sensor values.
4. The readings are compared with the programmed conditions.
5. The LED and buzzer provide an alert when the defined conditions are detected.
